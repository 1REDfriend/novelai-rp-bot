# NovelAI Roleplay Bot — บอท Discord แชทโรลเพลย์กับตัวละคร AI

[English](README.md) | **ภาษาไทย**

บอท **AI โรลเพลย์บน Discord** ที่รันบนเครื่องของคุณเอง ใช้ **NovelAI API** เขียนบทตอบ คุยกับตัวละครได้ทุกภาษารวมถึงภาษาไทย สร้างตัวละครใหม่ได้แค่คุยกับ AI แล้วยังวาดภาพฉากล่าสุดเป็นลายเส้นอนิเมะด้วย **NovelAI Diffusion V5** ได้ด้วย ทั้งหมดอยู่ในโควตาฟรีของแพ็ก Opus

ถ้าเคยเล่น Character.AI มาก่อน ให้นึกว่านี่คือเวอร์ชันส่วนตัวที่อยู่ในเซิร์ฟเวอร์ Discord ของคุณเอง ตัวละคร lorebook และประวัติแชททั้งหมดอยู่ในเครื่องคุณ

## ทำอะไรได้บ้าง

- **เล่นโรลเพลย์ได้ทุกช่อง** ผูกช่องกับตัวละครด้วย `/start` แล้วพิมพ์คุยได้เลย แต่ละช่องมีเรื่องของตัวเอง หลายคนเข้ามาเล่นฉากเดียวกันก็ได้
- **Memory, Lorebook และ Author's Note** จัด context แบบเดียวกับ NovelAI มี memory วางไว้บนสุดตลอด มี lorebook ที่โผล่มาเองเมื่อมีคนพูดถึง key และมี Author's Note ไว้คุมโทนกับความยาวคำตอบ
- **สร้างตัวละครด้วยการคุย** `/builder` เปลี่ยนช่องเป็นห้องทำตัวละคร เล่าว่าอยากได้แบบไหน หรือให้ AI คิดเองทั้งหมดก็ได้ แก้ไปคุยไป ดูหน้าตาด้วย `/image` พอใจแล้ว `/save` เป็นไฟล์พร้อมเล่น ตัวเก่าก็แก้แบบนี้ได้ บอทสำรองไฟล์เดิมไว้ให้
- **วาดภาพฉาก หน้าตาตัวละครไม่เพี้ยน** `/image` ให้ AI อ่านฉากล่าสุดแล้วเขียนเป็นแท็ก Danbooru ก่อนส่งไปวาดด้วย V5 Full หน้าตาตัวละครล็อกจากแท็กใน lorebook แต่ละช่องใช้ seed เดิม ภาพต่อภาพเลยยังจำตัวละครได้
- **ไม่เผลอเสีย Anlas** ค่าวาดภาพล็อกไว้ในระดับฟรี (ทีละ 1 ภาพ ไม่เกิน 28 steps ขนาดปกติ ไม่มีภาพอ้างอิง) ก่อนวาดทุกครั้งบอทเช็กโควตาก่อน เหลือน้อยก็ไม่วาด ถ้ายอด Anlas ลดลงเมื่อไหร่จะเตือนทันที
- **แชทผู้ช่วยธรรมดา** `/chat` เปลี่ยนช่องเป็นห้องคุยกับ GLM-4.6 ตรงๆ ไม่มีตัวละคร
- **ตัวช่วยเขียน prompt ภาพ** ตัวละคร `tagsmith` ที่แถมมา จะแปลงไอเดียภาพเป็นช่อง prompt ให้ก๊อปไปวางในหน้าเจนภาพของ NovelAI พร้อมค่าที่แนะนำ
- **คุมเรื่องได้** `/regen` เขียนคำตอบล่าสุดใหม่ `/undo` ถอนตาที่แล้ว `/reset` เริ่มใหม่จากข้อความเปิดเรื่อง `/note` เปลี่ยน Author's Note เฉพาะฉากนี้
- **ประวัติไม่หาย** แชทเก็บใน SQLite ปิดบอทแล้วเปิดใหม่ เรื่องก็ยังอยู่ ไฟล์ตัวละครเป็น YAML ธรรมดา แก้แล้วมีผลทันทีโดยไม่ต้องรีสตาร์ท
- **รองรับภาษาไทย** ตัวละครพูดไทยได้ งบ token กับการแบ่งข้อความปรับไว้สำหรับภาษาไทยแล้ว

## สิ่งที่ต้องมี

- Node.js 22.13 ขึ้นไป (บอทใช้ SQLite ที่มากับ Node เลยไม่ต้องลงอะไรเพิ่ม)
- บัญชี NovelAI ที่ subscribe อยู่ ส่วน `/image` ต้องเป็นแพ็ก **Opus**
- เซิร์ฟเวอร์ Discord ที่คุณมีสิทธิ์เชิญบอทเข้า

## 1. สร้างบอทใน Discord Developer Portal

1. เข้า https://discord.com/developers/applications แล้วกด **New Application** ตั้งชื่อตามใจ
2. ไปที่แท็บ **Bot** กด **Reset Token** แล้วคัดลอก token เก็บไว้ ค่านี้คือ `DISCORD_TOKEN`
3. ในหน้า **Bot** เลื่อนลงไปที่ **Privileged Gateway Intents** แล้วเปิด **Message Content Intent** ถ้าไม่เปิด บอทจะอ่านข้อความในช่องไม่ได้ ตัวละครก็จะไม่ตอบ
4. ไปที่ **OAuth2 → URL Generator**
   - Scopes: ติ๊ก `bot` และ `applications.commands`
   - Bot Permissions: ติ๊ก `View Channels`, `Send Messages`, `Read Message History`, `Embed Links`, `Attach Files`
5. คัดลอกลิงก์ด้านล่าง เปิดในเบราว์เซอร์ แล้วเลือกเซิร์ฟเวอร์ที่จะเชิญบอทเข้า

**แนะนำ:** ใส่ ID ของเซิร์ฟเวอร์ไว้ใน `DISCORD_GUILD_ID` ด้วย คำสั่ง slash จะขึ้นทันที ถ้าเว้นว่าง Discord อาจใช้เวลาถึงชั่วโมงกว่าคำสั่งจะโผล่ วิธีหา ID: เปิด **User Settings → Advanced → Developer Mode** แล้วคลิกขวาที่ชื่อเซิร์ฟเวอร์ เลือก **Copy Server ID**

## 2. เอา NovelAI token

1. ล็อกอิน https://novelai.net
2. เปิด **User Settings → Account** แล้วหา **Get Persistent API Token**
3. คัดลอก token (ขึ้นต้นด้วย `pst-`) ค่านี้คือ `NOVELAI_TOKEN`

token นี้เข้าถึงบัญชีของคุณได้ ห้ามแชร์ และห้าม commit ขึ้น git (`.env` อยู่ใน `.gitignore` แล้ว)

## 3. ติดตั้งและรัน

```bash
npm install
```

คัดลอก `.env.example` เป็น `.env` แล้วใส่ `DISCORD_TOKEN`, `NOVELAI_TOKEN` และ `DISCORD_GUILD_ID` ถ้ามี บรรทัดอื่นที่ยังเป็น `your-...` หรือเว้นว่างไว้ บอทจะใช้ค่าเริ่มต้นในตารางด้านล่างแทน แก้เฉพาะค่าที่อยากเปลี่ยนก็พอ

```bash
cp .env.example .env
```

(บน Windows ใน cmd ใช้ `copy .env.example .env`)

ก่อนรันบอทครั้งแรก ลองเช็ก NovelAI ก่อนว่า token ใช้ได้ และชื่อโมเดลถูก

```bash
npm run check-api
```

สคริปต์จะแสดงรายชื่อโมเดลที่ token ใช้ได้ แล้วลองให้ AI เขียนสั้นๆ หนึ่งครั้ง ถ้าชื่อโมเดลใน list ไม่ใช่ `glm-4-6` ให้แก้ `NOVELAI_TEXT_MODEL` ใน `.env` ตามชื่อที่เห็น

จากนั้นรันบอท

```bash
npm run dev
```

ถ้าขึ้น `Logged in as ...` แปลว่าพร้อมใช้ กด `Ctrl+C` เพื่อปิด

อยากรันแบบ build ก่อน (เริ่มเร็วกว่า): `npm run build` แล้วตามด้วย `npm start`

## วิธีเล่น

| คำสั่ง | ทำอะไร |
|---|---|
| `/start <ตัวละคร>` | ผูกช่องนี้กับตัวละคร ล้างประวัติเดิม แล้วส่งข้อความเปิดเรื่อง |
| พิมพ์ข้อความปกติ | ตัวละครตอบกลับ (เฉพาะช่องที่ผูกแล้ว) |
| `/regen` | ลบคำตอบล่าสุดของตัวละครแล้วเขียนใหม่ ใช้ได้ตอน AI ตอบพังด้วย |
| `/undo` | ลบข้อความล่าสุดของคุณกับคำตอบของตัวละครออกจากประวัติ |
| `/reset` | ล้างประวัติช่องนี้ เริ่มเรื่องใหม่จากข้อความเปิดเรื่อง |
| `/note <ข้อความ>` | เปลี่ยน Author's Note ของฉากนี้ชั่วคราว พิมพ์ `/note` เปล่าๆ เพื่อกลับไปใช้ค่าเดิม |
| `/chat` | เปลี่ยนช่องนี้เป็นแชทคุยกับ AI ผู้ช่วยแบบธรรมดา ไม่มีตัวละคร (ดูหัวข้อด้านล่าง) |
| `/builder [ตัวละคร]` | เปลี่ยนช่องนี้เป็นห้องคุยกับ AI เพื่อสร้างตัวละครใหม่ หรือแก้ตัวที่มีอยู่ (ดูหัวข้อด้านล่าง) |
| `/save [file] [overwrite]` | บันทึกไฟล์ตัวละครล่าสุดที่ AI เขียนในช่อง `/builder` |
| `/characters` | ดูรายชื่อตัวละครที่มี |
| `/image [orientation] [new_seed]` | วาดภาพฉากล่าสุด (ในช่อง `/builder` จะวาดหน้าตาตัวละครที่กำลังสร้างแทน) เลือกได้ว่าเป็นแนวตั้ง แนวนอน หรือสี่เหลี่ยมจัตุรัส (ค่าเริ่มต้นคือแนวตั้ง) ใส่ `new_seed: True` ถ้าอยากสุ่มลายเส้นใหม่ |

ชื่อที่ตัวละครเห็นคือชื่อแสดงผลของคุณในเซิร์ฟเวอร์ ถ้ามีหลายคนพิมพ์พร้อมกัน บอทจะตอบทีละข้อความตามลำดับ

## คุยกับ AI แบบผู้ช่วยด้วย `/chat`

อยากถามอะไรทั่วไปโดยไม่ต้องเล่นบทบาท ก็พิมพ์ `/chat` ในช่องที่ต้องการ ช่องนั้นจะกลายเป็นห้องคุยกับ GLM-4.6 ตรงๆ ประวัติเดิมของช่องจะถูกล้างทิ้ง แล้วพิมพ์ถามได้เลย

- บอทใช้รูปแบบแชทของ GLM-4.6 เอง คำตอบเลยยาวและเป็นขั้นตอนกว่าโหมดตัวละคร ยาวได้ถึงราว 1500 token (ปรับได้ที่ `CHAT_MAX_OUTPUT_TOKENS`)
- คำตอบยาวๆ อาจใช้เวลาราว 30–60 วินาที ระหว่างนั้นบอทจะขึ้นว่ากำลังพิมพ์
- `/regen`, `/undo`, `/reset` ใช้ได้เหมือนเดิม `/note` ใช้เพิ่มคำสั่งพิเศษให้ช่องนี้ เช่น `/note ตอบสั้นๆ ไม่เกิน 3 บรรทัด`
- `/image` ใช้ในโหมดนี้ไม่ได้
- อยากกลับไปเล่นบทบาท ก็ใช้ `/start <ตัวละคร>` ในช่องเดิมได้เลย

## สร้างหรือแก้ตัวละครด้วย `/builder`

ไม่ต้องเขียนไฟล์ YAML เอง คุยกับ AI แล้วให้มันเขียนให้

1. พิมพ์ `/builder` ในช่องว่างๆ สักช่อง ถ้าจะแก้ตัวที่มีอยู่แล้ว ให้เลือกชื่อในช่อง `character` เช่น `/builder character:aria`
2. เล่าตัวละครที่อยากได้ AI จะถามกลับทีละนิด ถ้าขี้เกียจตอบ บอกว่า "คิดที่เหลือเองแล้วแสดงไฟล์เลย" ก็ได้
3. AI จะแสดงไฟล์เต็มในกรอบโค้ด ไม่ชอบตรงไหนก็บอกให้แก้ได้เรื่อยๆ
4. พอใจแล้วพิมพ์ `/save` บอทจะเช็กไฟล์ก่อน ถ้าเขียนผิดรูปแบบจะไม่บันทึก และบอกว่าผิดตรงไหน
5. ไปช่องอื่นแล้ว `/start <ชื่อไฟล์>` เล่นได้เลย ไม่ต้องรีสตาร์ทบอท

เรื่องที่ควรรู้

- ชื่อไฟล์ตั้งจากชื่อภาษาอังกฤษของตัวละคร ถ้าชื่อเป็นภาษาไทยล้วน จะใช้ชื่ออังกฤษใน lorebook แทน หรือกำหนดเองได้ด้วย `/save file:ชื่อไฟล์`
- ตัวละครใหม่จะไม่ทับไฟล์ของตัวอื่น ถ้าชื่อซ้ำ บอทจะเตือน ถ้าตั้งใจทับจริงๆ ให้ใช้ `/save overwrite:True`
- ทุกครั้งที่เขียนทับ บอทจะเก็บไฟล์เก่าไว้เป็น `<ชื่อ>.yaml.bak` ในโฟลเดอร์ `characters` ถ้าอยากย้อนกลับ ก็ลบ `.bak` ท้ายชื่อออก
- หลัง `/save` แล้ว ช่องนี้จะแก้ไฟล์นั้นต่อ คุยต่อแล้ว `/save` ซ้ำได้เลย
- AI จะเขียน memory กับ lorebook เป็นภาษาอังกฤษ เพราะ GLM ทำตามได้ดีกว่า ส่วนข้อความเปิดเรื่องจะเป็นภาษาที่ใช้เล่น
- ตัวละครพูดไทย builder จะกำหนดคำแทนตัวที่เข้ากับตัวละครไว้คำเดียว เช่น ผู้หญิงใช้ ข้า หนู ดิฉัน หรือชื่อตัวเอง ผู้ชายใช้ ผม หรือ ข้า แล้วกำหนดด้วยว่าจะเรียกคุณว่าอะไร เขียนไว้ทั้งใน memory และ Author's Note บอทจะไม่ใช้ ฉัน เพราะส่วนใหญ่คนเล่นใช้คำนี้แทนตัวเองอยู่แล้ว อยากได้คำอื่นก็บอก builder ได้เลย
- ไฟล์เต็มยาวราว 4,000 ตัวอักษร บอทจะแบ่งส่งเป็น 2–3 ข้อความ แต่ละคำตอบรอราว 1 นาที
- ใช้ `/regen`, `/undo`, `/reset` ได้
- อยากเห็นหน้าตาตัวละคร พิมพ์ `/image` ได้เลย บอทจะวาดตัวละครยืนคนเดียวบนพื้นหลังเรียบ จาก `Image tags` ในไฟล์ฉบับล่าสุดที่ AI เพิ่งเขียน ไม่ต้อง `/save` ก่อน ถ้ายังไม่มีฉบับร่าง ก็ใช้ไฟล์ที่กำลังแก้อยู่ ไม่ถูกใจก็สั่ง AI แก้ Image tags แล้ว `/image` ใหม่ ภาพใช้ seed เดิมทั้งช่อง จะได้เห็นชัดว่าเปลี่ยนเพราะแท็ก ถ้าอยากสุ่มลายเส้นใหม่ ใส่ `new_seed:True` ใช้โควตาฟรีเหมือน `/image` ปกติ
- ทุกคนในช่องใช้ `/save` ได้ เหมือนคำสั่งอื่น

## ให้ AI เขียน prompt ไปเจนภาพเองด้วย `tagsmith`

ตัวละคร `tagsmith` ไม่คุยเล่น แต่จะแปลงไอเดียภาพเป็นช่อง prompt ให้ก๊อปไปวางในหน้าเจนภาพของ NovelAI บนเว็บ พิมพ์ `/start tagsmith` แล้วเล่าภาพที่อยากได้ เป็นไทยหรืออังกฤษก็ได้ บอทจะตอบกลับเป็นช่องตามนี้

- **Main prompt**: จำนวนคน สถานที่ แสง มุมกล้อง ลายเส้น
- **Character 1, 2, ...**: หน้าตา ชุด ท่าทางของแต่ละคน ถ้าคนในภาพทำอะไรต่อกัน จะใส่ `source#` / `target#` ให้ เช่น `source#hug`
- **Character N undesired**: สิ่งที่ไม่อยากให้มีกับคนนั้นๆ (`-` คือไม่มี)
- **Undesired content**: สิ่งที่ไม่อยากให้มีในภาพ ใส่แค่ของเฉพาะภาพนี้ ส่วนพวกภาพเสีย มือเพี้ยน ให้เลือก preset **Heavy** ในช่อง Undesired Content บนเว็บ
- **Settings**: ค่าที่แนะนำให้ตั้ง

ได้ภาพไม่ถูกใจ ใช้ `/regen` ให้เขียนใหม่อีกแบบได้ ส่วน `/image` ในช่องนี้จะไม่ได้ผลที่ต้องการ เพราะ `/image` วาดจากเรื่องในแชท ไม่ใช่จาก prompt

## สร้างภาพด้วย `/image`

พิมพ์ `/image` ในช่องที่กำลังเล่นอยู่ บอทจะทำ 3 ขั้น

1. ให้ AI อ่านเรื่องล่าสุด แล้วเขียนคำบรรยายภาพเป็นแท็กภาษาอังกฤษ แยกเป็นส่วนฉาก (`Main`) กับส่วนของแต่ละตัวละคร คำบรรยายนี้ไม่ถูกบันทึกลงประวัติแชท ตัวละครเลยไม่ไปเลียนแบบ
2. ถ้า AI เขียนผิดรูปแบบ บอทจะให้เขียนใหม่ 1 ครั้ง ถ้ายังผิดอีก จะบอกในแชท
3. ส่งไปวาดด้วย V5 Full แล้วโพสต์ภาพพร้อมคำบรรยายที่ใช้ เอาไปแก้ต่อใน NovelAI ได้เลย

### ทำให้ตัวละครหน้าตาเหมือนเดิมทุกภาพ

- **หน้าตาถูกล็อกจาก lorebook:** บรรทัด `Image tags (<ชื่อ>): ...` บอทจะใส่ลงภาพให้เองทุกครั้งแบบเดิมเป๊ะ AI เขียนแค่สิ่งที่เปลี่ยนในฉาก เช่น ท่าทาง สีหน้า หันไปทางไหน ถืออะไร จะเปลี่ยนชุดหรือทรงผมได้ก็ต่อเมื่อในเรื่องเขียนไว้ชัดเจน
- **ใส่แท็กให้ครบทั้งตัว:** ความยาวและทรงผม สีผม สีตา เสื้อ ท่อนล่าง รองเท้า และของติดตัว ส่วนที่ไม่ได้ใส่ โมเดลจะเดาใหม่ทุกภาพ เช่น ไม่ได้บอกท่อนล่าง กระโปรงก็อาจกลายเป็นกางเกงยีนส์
- **ใส่หน้าตาของคุณเองด้วย:** ไม่อย่างนั้นตัวคุณในภาพจะเปลี่ยนทุกรอบ เพิ่ม entry ใน lorebook ใส่ `always_on: true` และบรรทัด `Image tags (<ชื่อแสดงผลใน Discord>): ...` ดูตัวอย่างที่ comment ไว้ใน `characters/aria.yaml`
- **seed เดิมตลอดเรื่อง:** แต่ละช่องใช้ seed เดิมทุกภาพ ลายเส้นจะนิ่ง ถ้าอยากได้ลายเส้นแบบอื่น ใช้ `/image new_seed: True` บอทจะสุ่ม seed ใหม่แล้วใช้ seed นั้นต่อไป และพอใช้ `/start` seed จะเริ่มใหม่

ถึงจะทำครบทุกข้อ ภาพก็ยังต่างกันได้นิดหน่อย การล็อกให้เหมือนเป๊ะต้องใช้ภาพอ้างอิงตัวละคร (Character Reference / Vibe Transfer) ซึ่งเสีย Anlas บอทเลยไม่ใช้

**ไม่เสีย Anlas:** บอทล็อกค่าไว้ในโค้ด ใครสั่งเกินไม่ได้

- วาดทีละ 1 ภาพ ขนาดเลือกได้แค่ 832×1216, 1216×832 หรือ 1024×1024 ใช้ 28 steps และไม่มีภาพอ้างอิงหรือ Vibe Transfer
- ใช้แค่ V5 Full ไม่สลับไปรุ่นอื่น
- แพ็ก Opus วาด V5 ได้ฟรีแค่ในโควตาที่ค่อยๆ เติมเอง ก่อนวาดทุกภาพ บอทจะเช็กโควตาก่อน ถ้าเหลือต่ำกว่า 2% หรือเช็กไม่ได้ บอทจะไม่วาด และบอกในแชทว่าอีกนานแค่ไหนจะวาดได้อีก
- หลังวาด บอทเทียบยอด Anlas ก่อนกับหลัง ถ้าลดลงจะเตือนในแชททันที ส่วนท้ายของภาพจะบอกว่าโควตาเหลือกี่ %

## เพิ่มตัวละครเอง

คัดลอก `characters/aria.yaml` เป็นไฟล์ใหม่ เช่น `characters/ren.yaml` แล้วแก้เนื้อหา ชื่อไฟล์ (ไม่รวม `.yaml`) คือชื่อที่ใช้ใน `/start ren` แก้ไฟล์แล้วมีผลกับข้อความถัดไปทันที ไม่ต้องรีสตาร์ทบอท

ช่องในไฟล์:

- `name` ชื่อตัวละคร ใช้เป็นชื่อในบทสนทนา
- `memory` ข้อมูลหลักของเรื่อง วางไว้บนสุดของ context ทุกครั้ง
- `lorebook` รายการข้อมูลเสริม แต่ละอันมี
  - `keys` คำที่ใช้เรียก entry นี้ ถ้าคำไหนโผล่ในข้อความล่าสุดไม่กี่ข้อความ entry นี้จะถูกใส่เข้า context (จำนวนข้อความที่ดูตั้งได้ที่ `LOREBOOK_SCAN_DEPTH`)
  - `text` เนื้อหาที่จะใส่
  - `always_on` ตั้งเป็น `true` ถ้าอยากให้ใส่ทุกครั้ง
  - entry ของตัวละครควรมีบรรทัด `Image tags (<ชื่อ>): ...` เป็นแท็ก Danbooru ภาษาอังกฤษ ไว้ใช้ตอนสร้างภาพ
  - entry ของสถานที่ใส่บรรทัด `Scene tags (<ชื่อสถานที่>): ...` เป็นแท็กฉากหลังได้ (ไม่ใส่คน เวลา หรือสภาพอากาศ) `/image` จะวาดสถานที่นั้นออกมาหน้าตาเดิมทุกครั้ง สถานที่เริ่มเรื่องให้ตั้ง `always_on: true`
- `authors_note` คำสั่งสั้นๆ ที่แทรกไว้ใกล้ท้าย context คุมสไตล์การตอบ (ใส่ในเครื่องหมายคำพูด)
- `greeting` ข้อความเปิดเรื่อง

ถ้าไฟล์ไหนเขียนผิด บอทจะข้ามไฟล์นั้น แล้วบอกสาเหตุใน `/characters` และในหน้าต่างที่รันบอท

## ตั้งค่าเพิ่มเติม (`.env`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `MAX_OUTPUT_TOKENS` | 500 | ความยาวคำตอบสูงสุดต่อครั้ง ภาษาไทยใช้ราว 1 token ต่อ 1 ตัวอักษร ถ้าคำตอบชนเพดาน บอทจะให้ AI เขียนต่ออีกไม่เกิน 120 token ให้จบประโยค ถ้ายังไม่จบอีก จะตัดกลับไปที่ประโยคสุดท้ายที่ครบ |
| `MAX_CONTEXT_TOKENS` | 8000 | ขนาด context ทั้งหมด เกินเมื่อไหร่ ประวัติเก่าสุดจะถูกตัดก่อน Memory, Lorebook และ Author's Note ไม่ถูกตัด |
| `TEMPERATURE` / `TOP_P` | 0.7 / 0.95 | ความหลากหลายของคำตอบ |
| `LOREBOOK_SCAN_DEPTH` | 4 | ดู key ของ lorebook ย้อนหลังกี่ข้อความ |
| `AUTHORS_NOTE_DEPTH` | 1 | แทรก Author's Note ก่อนท้ายประวัติกี่ข้อความ |
| `CHAT_MAX_OUTPUT_TOKENS` | 1500 | ความยาวคำตอบสูงสุดในโหมด `/chat` |
| `BUILDER_MAX_OUTPUT_TOKENS` | 3000 | ความยาวคำตอบสูงสุดในโหมด `/builder` ต้องพอให้ไฟล์ตัวละครเต็มไฟล์ |
| `BUILDER_MAX_CONTEXT_TOKENS` | 16000 | ขนาด context ของโหมด `/builder` (รวมไฟล์ที่กำลังแก้และประวัติการคุย) |
| `STORY_DIRECTIVE` | กฎในตัวบอท | กฎของเรื่องที่แทรกต่อท้าย Author's Note ทุกตัวละครในโหมดโรลเพลย์ ให้ตัวละครคิดเองและพาเรื่องเดินต่อ ทำสิ่งที่คุณเริ่มให้จบ และไม่พูดประโยคซ้ำ `{{char}}` จะถูกแทนด้วยชื่อตัวละคร ใส่ `off` เพื่อปิด |
| `NOVELAI_CHAT_URL` | `https://text.novelai.net/oa/v1/chat/completions` | endpoint ของโหมด `/chat` และ `/builder` ปกติไม่ต้องแก้ |
| `DATABASE_PATH` | `data/bot.db` | ที่เก็บประวัติแชท |

บอทนับ token แบบประมาณ (ไม่ได้ใช้ tokenizer จริง) และเผื่อไว้มากสำหรับภาษาไทย ถ้า NovelAI แจ้งว่า context ยาวเกิน ให้ลด `MAX_CONTEXT_TOKENS` ลง
